# Emoji Game

## Overview
Welcome to the Emoji Game! This exciting game challenges your memory and speed as you race against the clock to match emojis based on various themes. Perfect for all ages, this game is a fun way to test your emoji recognition skills.

## How to Play
1. **Game Setup**: Choose your preferred theme (e.g., Animals, Food, Sports).
2. **Match Making**: You'll be presented with a grid of emojis.
3. **Objective**: Find and pair identical emojis before the time runs out!
4. **Scoring**: Earn points for each successful match.
5. **Time Limit**: Complete the game within the given time frame for a bonus!

## Getting Started
To get started with the Emoji Game:
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/Fmacmak/emoji-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd emoji-game
   ```
3. Open the `index.html` file in your favorite browser.

- Intuitive user interface
